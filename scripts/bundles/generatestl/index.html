GenerateSTL

Gears, screws, bearings, boxes, grilles and pegboards as printable STL files. Everything is made on this computer; nothing is sent anywhere.

Advanced

Starting the generator. The first start takes a few seconds.

Geometry engine by Fabian (nicremo), MIT licence (LICENSE-engine.txt), from github.com/nicremo/generatestl. It runs here with Pyodide (MPL-2.0) and pydantic (MIT); the preview uses three.js (MIT). The original site, with guides for each part, is generatestl.com.
